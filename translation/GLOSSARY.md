# 용어집

한글 패치에서 쓰는 주요 용어 210개입니다. 번역을 고칠 때 이 표기를 따라 주세요.
용어 자체를 바꾸자는 의견은 [이슈](../../../issues/new/choose)로 남겨 주세요.

## 번역 원칙

- 카드·유물 설명은 '~합니다'체로 짧게 씁니다. 예: Deal `#a` damage. → 피해를 `#a` 줍니다.
- 수치가 붙는 키워드는 '키워드 N' 순서를 유지합니다. 예: Apply Vulnerable 2 → 취약 2 부여 / Block 5 → 방어도 5
- `[k]…[/k]` 등 모든 태그와 `#a`, `{name}`, `[0]` 같은 자리표시자는 그대로 둡니다. 태그 안의 단어만 번역합니다.
- 고유명사(카드·유물·몬스터 이름)는 뜻을 살려 번역하고, 이름이 설명문에 나오면 용어집 표기와 똑같이 씁니다.
- 한자·가나·악센트 문자는 쓰지 않습니다. (새 한글 글자는 괜찮습니다. 반영할 때 폰트를 다시 만듭니다.)
- UI 버튼·메뉴는 명사형으로 짧게 씁니다. 예: New Game → 새 게임
