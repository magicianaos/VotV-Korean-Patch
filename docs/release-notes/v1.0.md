## Vault of the Void 한글 패치 v1.0

게임 안의 모든 문장(6,321줄)을 번역한 첫 배포판입니다.

**대상 게임 버전:** Steam 2.8.9.0

### 설치
1. 아래 **Assets**에서 `VotV_Korean_Patch_v1.0.zip`을 받아 압축을 모두 풉니다.
2. 게임을 종료하고 `Install.bat`을 더블클릭합니다.
3. 게임에서 **Options → Language → Korean**을 고릅니다.

제거는 `Uninstall.bat` 또는 Steam의 "게임 파일 무결성 검사"로 할 수 있습니다.

### 포함 내용
- 카드·유물·몬스터·주문·이벤트·튜토리얼·메뉴 전체 번역
- 한글 폰트 (Noto Sans CJK KR, SIL OFL 1.1)
- 자동 설치·제거 프로그램 (원본 자동 백업)
- 번역 검수용 엑셀 `KR_translation_review.xlsx`

### 파일
| 파일 | 설명 |
|---|---|
| `VotV_Korean_Patch_v1.0.zip` | 설치 파일 (이것만 받으면 됩니다) |
| `KR_translation_review.xlsx` | 번역 수정 제안용 엑셀 (압축 파일 안에도 있음) |

오역이나 어색한 문장은 저장소의 **Issues** 탭에서 알려 주세요.
